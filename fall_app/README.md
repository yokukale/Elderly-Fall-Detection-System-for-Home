# 居家防跌倒守护微信小程序 (`fall_app`)

面向家人日常监护的微信小程序，与 **STM32F407 + K230 视觉跌倒检测 + ESP-01S + 华为云 IoTDA** 硬件系统配套使用。

## 功能概览

1. **居家守护 (`pages/index`)**
   - 实时守护状态大卡：区分「当前安全平稳」「疑似跌倒报警」「K230 视觉离线」「设备离线」。
   - 手机端声光/震动提醒：跌倒状态首次触发时自动播放本地提示音 (`assets/audio/alert.mp3`) 并长震动，支持本机一键静音。
   - 一键紧急拨号：直接调用 `wx.makePhoneCall` 呼叫预设紧急联系人。
   - 远程硬件控制：下发华为云物模型命令 `MUTE`（远程消音）与 `RESET`（解除/复位）。
   - 画面区域可视化：基于 K230 上报的 640×480 `bbox` 坐标在手机端还原跌倒区域位置（如中间区域 / 偏左 / 偏右等）。
   - 本地模拟演练模式：支持在未接硬件或未填 IAM 密码前直接演练正常、跌倒、视觉离线与设备离线场景。

2. **告警记录 (`pages/history`)**
   - 统计今日跌倒次数、待处置告警数与累计守护事件。
   - 支持按「全部 / 跌倒 / 设备 / 操作」分类筛选时间轴，展示跌倒处置状态（报警中 / 已消音 / 已解除）、置信度及位置区域。
   - 自动去重并持久化到本机缓存（最多保留 100 条）。

3. **守护设置 (`pages/settings`)**
   - 看护档案设置：长辈称呼、监护区域、紧急联系人姓名及电话。
   - 提醒与轮询偏好：本地模拟演练开关、自动轮询开关与频率（2 秒 / 3 秒 / 5 秒）、响铃与震动开关及试听测试。
   - 华为云 IoTDA 参数管理：已预填当前账号实例与设备参数，提供 IAM 子账号密码输入、连接测试、Token 缓存清理与恢复默认参数功能。

## 使用与调试步骤

### 1. 用微信开发者工具打开项目
1. 启动微信开发者工具，导入目录 `D:\13598\Desktop\falling\fall_app`。
2. 在右上角 **「详情」->「本地设置」** 中：
   - 确认 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」** 已勾选（开发阶段必须开启）。
   - 若工具提示使用独立 TypeScript / LESS 编译插件，保持项目自带的 `useCompilerPlugins: ["typescript", "less"]` 即可。

### 2. 先体验本地模拟演练（可选）
- 若尚未配置 IAM 子账号，在首页引导卡点击 **「先开启模拟演练」**（或在「守护设置」打开 **「本地模拟演练模式」**），即可在首页切换「恢复平稳」「模拟跌倒报警」「模拟视觉离线」「模拟设备离线」并测试响铃、远程消音、解除复位和时间轴记录。

### 3. 连接真实华为云硬件
1. 登录华为云控制台，进入 **「统一身份认证 IAM -> 用户」**，在账号 `hid_4cmd1am6hdsyxmj` 下创建一个 IAM 子用户，并赋予 IoTDA 访问权限（如加入 `admin` 或带有 `IoTDA ReadOnlyAccess` + 命令下发权限的用户组）。
2. 在小程序 **「守护设置」** 页填写 `IAM 子用户名` 与 `密码`，点击 **「测试华为云连接」** 验证能获取设备状态及影子数据，再点击 **「保存云端配置」**。
3. 若需发布真机体验版/正式版，请在微信公众平台 **「开发管理 -> 开发设置 -> 服务器域名」** 的 `request合法域名` 中添加：
